Estrutura para Atualização da Base

Esta solução foi preparada para receber novas linhas na planilha original preservando histórico e configurações editáveis.

  1. Substitua/atualize o arquivo fonte:
  2. Execute o script de atualização: python build_data.py (na pasta do dashboard).
  3. O script reimporta os registros, remove duplicidades de Ordem, atualiza indicadores/gráficos/rankings/filtros e preserva config/classificacao_areas.json, config/classificacao_status.json e config/metas.json (mantendo ajustes já feitos e adicionando novas áreas/status encontrados).
  4. Reabra/atualize esta página (index.html) para carregar os dados atualizados.
Regra aplicada na atualização: ordens duplicadas não são contadas mais de uma vez; mês/ano derivados de "Data-base do início"; área derivada de "Local de instalação"; sem inventar informações ausentes (ex.: metas permanecem "não informadas" até cadastro).
